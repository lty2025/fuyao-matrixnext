扶摇 SOAR
可审批、可审计的浏览器智能体

用一句自然语言，让智能体「鹏」在真实网页上观察、点击、输入、总结；高风险操作必须经过你审批，每一步都留下审计记录。

01项目概述

扶摇（SOAR）是一个 AI 原生浏览器：它不是给浏览器加一个聊天框，而是把「智能体能真实操作网页」和「操作必须可被信任」放在同一个产品里。

  • 形态：Windows 桌面应用，免安装便携版；启动即用，数据保存在同目录 profile。
  • 智能体：内置「鹏」，可执行多步浏览器任务，操作过程可视化。
  • 定位：不是“更聪明的浏览器”，而是浏览器智能体的可信执行层——能做事，也能说清楚做了什么、为什么做、谁批准的。
  • 模型：OpenAI 兼容接口，支持 DeepSeek、火山方舟、阿里云百炼、智谱 GLM、比赛主推的 MOI Genesis，以及自定义地址；无 Key 时可用 mock 演示模式。

02问题：智能体的信任缺口

浏览器智能体已经能点网页，但要在真实工作里被信任，至少有三个问题：

操作不可信

模型幻觉或误判会触发支付、删除、发送等不可逆动作；缺少分级与人工确认。

过程不可见

用户只看到最终结果，不知道它点了什么、填了什么、访问了哪里；出问题无法追溯。

结果不可靠

模型可能“嘴上完成”——没有调用任何工具就宣称任务完成。

企业场景还多一层：合规与数据边界。谁批准了高风险操作？密码有没有落日志？智能体能不能碰本地文件？

03方案：可信执行闭环

扶摇把智能体执行拆成五段闭环：观察 → 决策 → 操作 → 审批 → 审计，每一段都有对应的工程机制。

环节机制用户感知
观察页面蓝图：把当前视口的可交互元素提取成带编号的列表（ref、标签、类型、文本、坐标）鹏按元素引用操作，不是盲点坐标
决策上下文压缩 + 任务账本（目标/事实/完成/失败）+ 循环检测长任务不爆上下文，卡住会换策略
操作ActionExecutor：点击、输入、按键、滚动、导航；虚拟光标与打字气泡屏幕上看得到它正在做什么
审批L0–L3 分级；L2 弹窗审批，L3 直接拒绝高风险操作先问你；拒绝后不重试
审计工具调用、审批、急停、语音、设置变更写入 JSONL；敏感输入脱敏事后可查、可导出

零操作守卫

当任务包含「打开/搜索/点击/输入/删除…」等需要实际操作的动词，而鹏在执行任何真实工具之前直接调用 done 或给出文字回答时，守卫会拦下并要求它真实执行（最多 3 次提醒）；仍为空操作则终止任务并报错。如果任务明确写了「不要操作 / 凭你的知识回答」，守卫会豁免。

04技术栈与架构

层实现
应用外壳Electron（Chromium 内核）+ React；多标签使用 WebContentsView；主窗口为无边框自绘标题栏
智能体AgentSession：系统提示、页面蓝图、工具调用循环、上下文估算与压缩、任务账本、LoopGuard、零操作守卫
操作执行ActionExecutor：基于蓝图元素中心坐标点击；输入前全选旧内容再逐字输入并回读校验；操作前自动恢复并聚焦主窗口
安全策略classifyAgentTool：L0 只读 / L1 可逆 / L2 高风险 / L3 禁止；L2 进入审批；L3 直接返回错误
审批独立 BrowserWindow 模态卡片，显示工具、原因、参数摘要；120 秒未处理自动拒绝；敏感输入显示为 ••••••
审计audit.jsonl 追加写入，超过 5MB 轮转为 audit.old.jsonl；敏感输入在本会话内做全链路脱敏
模型接入OpenAI 兼容 /chat/completions（含 function calling）；提供方预设与“获取模型”；Base URL 规范化与错误归类
语音渲染进程录音（16kHz 单声道 WAV、静音检测）；主进程 whisper-server 常驻识别，失败回落 whisper-cli；简体中文提示词
插件manifest 声明权限；沙箱 iframe；宿主转发 RPC；主进程逐项校验；插件可注册为鹏的 AI 工具
安全边界contextIsolation + sandbox；网页 nodeIntegration 关闭；IPC 来源校验；默认拒绝敏感权限；L3 拦截 file://、javascript:、浏览器内部页
分发GitHub Pages 作品页；GitHub Releases 安装包；便携模式 FUYAO_USER_DATA_DIR，配置与缓存随包

上下文与稳定性

  • 每轮把页面蓝图与历史消息一起估算 token；接近窗口上限时自动压缩历史，并把关键事实保底写入任务账本。
  • LoopGuard 检测重复动作与短周期振荡；零操作守卫检测“未执行就结束”。
  • 所有等待与工具执行都可被“停止”中断；停止后不会继续点击或提交。

能力常见做法扶摇

07使用说明

安装与启动

  1. 从 Releases 下载：
    • 轻量版：单个 zip，约 169MB，不含语音模型；
    • 完整版：单个 fuyao-full.7z（约 581MB），下载后用 7-Zip 解压。
  2. 解压后双击「启动演示.bat」。首次启动会在同目录创建 profile，配置与缓存不写入系统。
  3. 系统要求：Windows 10 / 11 x64；程序未签名，SmartScreen 提示时选择「仍要运行」。

零配置演示（无需 Key）

默认使用 mock 演示模式，启动后会自动打开本地演示页。在右侧「鹏」输入 搜索 DeepSeek，按 Ctrl+Enter 或点发送：鹏会输入关键词、提交搜索、点击结果，落到详情页。

接入真实模型

  1. 打开「设置 → AI 模型」；
  2. 选择提供方：MOI Genesis（比赛推荐）、DeepSeek、火山方舟、阿里云百炼、智谱 GLM 或自定义 OpenAI 兼容地址；
  3. 填入 API Key；Genesis 的 Base URL 以 MOI 控制台「使用」页为准（默认已填 https://token.moi.matrixorigin.cn/v1）；
  4. 点「获取模型」选择模型，再点「设为当前使用」。

语音与快捷键

  • 点鹏输入框里的 🎤，或按 Ctrl+Shift+Space；说完停顿约 1 秒自动结束，识别结果填入输入框。
  • 急停：Ctrl+Alt+Escape；快捷键可在「设置 → 快捷键与安全」中录制与清除。

审批与审计

  • L2 操作会弹出审批卡片；允许一次或拒绝，120 秒未处理自动拒绝；
  • 审计位于「设置 → 快捷键与安全 → 审计日志」，可刷新、打开目录、导出；
  • 若开启「自动批准 L2（不推荐）」，高风险操作不再询问，但仍写入审计。

08场景与业务价值

对应创意赛道的「流程自动驾驶」：把高频、重复、跨站的浏览器流程交给鹏执行，同时用审批与审计让它可被团队接受。

场景鹏做什么治理如何介入
采购信息收集与比价跨多个供应商站点收集价格、规格、库存，汇总对比表单提交与购买类按钮触发 L2 审批；审计保留访问轨迹
跨站资料汇总一个任务里打开多个页面，抽取要点生成日报每次工具调用、访问 URL 都留痕，便于复核来源
重复表单与后台操作登录、填写、提交等流程密码类输入在审批与审计中打码，不落明文

业务价值：减少重复操作时间与人为错误；把“交给智能体”从个人习惯变成团队可审批、可追责的流程；模型可替换，避免被单一厂商锁定。

09安全与隐私

  • 数据流：页面内容只在执行任务时发送给你选择的模型服务；应用本身不接入统计或遥测。
  • 密钥：API Key 通过系统安全存储（Windows DPAPI / Electron safeStorage）加密保存在本地。
  • 本地语音：whisper 在本机运行，录音不会上传。
  • 操作边界：L3 拒绝本地文件、脚本 URL 和浏览器内部页面；网页标签启用 sandbox + contextIsolation，关闭 nodeIntegration。
  • 审计：只写本地文件；敏感输入在审批详情、工具结果、模型总结中均脱敏。
  • 插件：manifest 声明权限，主进程逐项校验；插件不能直接访问文件系统。

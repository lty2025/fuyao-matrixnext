# 扶摇 SOAR · 可审批、可审计的浏览器智能体

MatrixNEXT 2026 · AI BUILDER FESTIVAL · 创意赛道（流程自动驾驶）参赛作品。

扶摇是一个 AI 原生浏览器：用一句自然语言，让内置智能体「鹏」在真实网页上观察、点击、输入、总结。高风险操作必须经过用户审批，全部工具调用写入审计日志；模型可自由切换（DeepSeek / 火山方舟 / 阿里云百炼 / 智谱 GLM / MOI Genesis / 自定义 OpenAI 兼容接口）。

## 核心能力

- **可视化操作**：页面蓝图 + 元素引用，虚拟光标、点击涟漪与打字气泡
- **安全层 L0–L3**：只读 / 可逆自动执行 / 高风险审批 / 禁止类直接拒绝
- **审批**：L2 操作弹窗确认，120 秒未处理自动拒绝，敏感输入自动打码
- **审计**：工具调用、审批、急停、语音、设置变更写入 JSONL，超 5MB 轮转
- **零操作守卫**：模型未执行任何真实操作时不允许结束任务
- **离线语音**：whisper.cpp 本地识别，识别结果直接填入任务输入框
- **插件与快捷键**：页面摘要、划词翻译；全局语音/急停快捷键与内置设置页

## 运行

Windows 10 / 11 x64。从 Releases 下载便携版，解压后双击「启动演示.bat」。默认 mock 演示模式无需 API Key；接入真实模型请在「设置 → AI 模型」中配置。
